# In Line｜排着呢

In Line 是一款通用的 Windows 本地取号与事项队列工具。它适合个人或内部支持岗位记录任务、展示排队顺序、发送取号卡片，适合业务量较大的职能部门使用。

当前代码版本：`v0.1.4`（2026-08-07，测试版）；当前公开发布版本为 `v0.1.3`。完整变更见 [CHANGELOG.md](CHANGELOG.md)。

## 主要功能

- **自动取号**：每日号码从 01 开始，跨天事项使用字母前缀标识。
- **队列调度**：支持手动调序、加急前移、暂缓管理和逾期事项优先显示。
- **桌面悬浮窗**：无需打开主界面即可查看队列、调整顺位或新增事项。
- **取号卡片**：点击列表右侧复制按钮即可生成高清竖版卡片，展示号码、事项信息和前方待处理数量。
- **事项管理**：部门 / 团队与对接人均支持多选，并可记录事项类型、状态、优先级和截止时间。
- **处理统计**：按本周、上周、月、季度或自定义区间统计已处理事项、完成率、处理结果、事项类型和趋势。
- **快捷筛选**：待办队列、历史归档和回收站均可按常用字段筛选。
- **归档恢复**：支持事项完成、归档、移入回收站以及后续恢复。
- **数据保护**：数据保存在本地 SQLite 数据库，并提供操作记录、自动备份和安全恢复。
- **后台运行**：支持系统托盘、开机启动和后台运行；软件无需联网，不包含遥测。

## 数据兼容与位置

v0.1.4 会继续使用：

`%APPDATA%\in-line\inline.db`

首次迁移旧数据库时，会先在 `backups` 目录生成 `InLine-backup-日期时间-before-migration.db`。旧格式备份会在启动时统一整理名称。应用更新或卸载不会主动删除用户数据库。

### 从旧版升级

1. 从托盘菜单正常退出旧版 In Line，确认任务管理器中不再有 `In Line.exe`。
2. 如果“设置 → 应用”仍显示 **In Line 0.0.1**，先卸载该 Electron 旧版。卸载不会删除 `%APPDATA%\in-line\inline.db`。
3. 删除或取消固定仍指向旧安装目录的快捷方式。
4. 安装并启动 v0.1.4；程序会沿用现有数据库和设置。
5. 在主界面左下角确认显示 `v0.1.4`，再核对原有事项、号码和日志。

迁移失败时会回滚数据库，不会按新项目清空原有数据。首次升级前仍建议保留一份手动备份。

如果主界面一直停在“正在整理队列”，修复后的程序会显示真实错误和“重新载入”按钮，不再无限等待；悬浮窗的“新增取号”会直接打开主界面的新增表单。

## 构建产物

Windows x64 安装包采用 NSIS 格式，使用系统 WebView2，不捆绑完整浏览器运行时。源码仓库不提交安装包二进制；正式安装包通过 GitHub Releases 提供。

v0.1.4 测试安装包：

- `In Line_0.1.4_x64-setup.exe`
- 本地测试构建提供 SHA-256 校验值；正式版本仍通过 GitHub Release 工作流发布

## 开发

推荐环境：

- Windows 10 / 11 x64
- Node.js 20+
- Rust stable-msvc
- Visual Studio 2022 Build Tools（Desktop development with C++）
- Microsoft Edge WebView2 Runtime

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npm.cmd run dist
```

前端为 React + TypeScript + Vite；桌面层为 Tauri 2 + Rust；数据层为 rusqlite + SQLite。

## 安全和隐私

- 纯本地应用，不会上传数据，不包含遥测或第三方统计。
- 前端不能执行任意 SQL，只能调用白名单命令。
- 日志不记录完整事项详情和内部备注。
- 备份恢复前会校验 SQLite 完整性，并自动备份当前数据。
