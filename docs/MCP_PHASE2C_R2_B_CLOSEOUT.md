## 安装遇到长时间等待时

1. 安装保护辅助程序长时间挂起时，安装器可能持续等待；当前不保证所有事务都能在固定时间内取消或退出。等待不等于成功，也不能仅凭超时判断已经失败。
2. 不要直接强制结束 PowerShell、NSIS、In-Line 或相关 MCP 进程，也不要按名称批量结束进程。保留等待时长、安装目录、错误提示及已有脱敏日志，交由维护人员确认状态。
3. 在安装状态尚未确认前，不要再次运行安装器或开始卸载。
4. 若安装目录内存在 `.in-line-install-transaction`，保留其中原始 `journal.xml`、备份及相关日志。不要删除标记、改写 journal 或覆盖程序文件来绕过保护；恢复须另行核对归属、文件和元数据。
5. 活跃文件锁与恢复资料不同：原持有进程退出后，其原句柄不再活跃，子进程或其他进程仍可能占用文件；journal/备份则可在进程退出后继续保留。无锁不代表事务完成，恢复目录存在也不证明原进程仍活着。

这些是用户操作说明和兼容性限制，不表示本轮新增了实时进度、超时处理或自动恢复功能。正式发布前仍须独立确认风险接受与发布门禁；选择 B 不自动豁免任何失败或未验项目。
