# 技术诊断、故障与AI审计维护（P7，待P8统一验收）

## 客户端自查

`get_diagnostic({errorId})`是第16个工具。使用已返回的请求编号，必须通过该客户端认证、常规读取、全局暂停与撤销检查；只读自身的7天技术摘要，不提供自由日志浏览。协议参数校验、客户端本地认证或连接失败若尚未到达主程序，可能没有主程序记录，`not_found`不能证明调用成功。请求编号与后台任务、执行轮次及审计编号关联；不得通过另起服务实例伪造当前会话接入。

技术事件只接受工具/模块/代码/时间/耗时、版本及不透明关联编号。排除Token、请求正文、操作缘由、业务说明、联系人、文件路径、原始SQL及自由日志。事件环最多2000条、7天；私有诊断目录8MiB，最多256类故障，空间不足保留最后有效记录并提示，不按年龄删除未解决故障。私有文件损坏、未知格式或权限异常不覆盖为默认空文件。

## 故障轮次

同客户端/工具/错误代码的持续异常累积同一轮证据。恢复后复发创建新轮，滚动30天至少3个独立轮次提升排查关注，不自动提升缺陷级别或AI权限。软件内“待验证”只表达意图：相关功能实际成功、当前权限/数据及私有存储有效，至少两次成功且首末间隔30秒，才可自动恢复；历史结果不充当当前恢复证明。写入结果不明先用原幂等键核验，禁止换键或盲目重放。

已恢复摘要30天后清理；未解决摘要持续保留。归档只是收起，不等于恢复。普通故障可静音7天，到期或风险上升解除；P0/P1不能静音。只有已恢复的摘要可由用户明确清理。界面只有基础状态筛选，不提供组合搜索或独立分析页面。

写入结果不明须匹配原回执关联标识并核实审计编号。关联标识是主程序从幂等键计算的技术引用，不保存原键文本；另一请求的成功不能解除该原请求故障，也不能把不同未确认写入合并为一次已恢复结果。

只复用前阶段已有的有限技术恢复：后台只读基准变化最多完整重查一次、限流暂停最多30分钟、可靠检查点恢复最多24小时。诊断不会自动修复业务、恢复库、改授权、重放写入或延长期限。

## 导出与审计

软件内选择CSV/JSON、预览完整脱敏内容，再一次确认保存。预览在RAM中保留10分钟，最多两份，每份最多16MiB；取消不写文件。确认使用预览nonce，原生命令不接受调用方文件正文。新建目标文件，拒绝覆盖、私有配置/业务数据目录及异常路径；实际读回字节必须与预览一致。不生成故障SHA校验清单或签名，不上传、不自动调用Codex。用户可手动复制标准提示词并附上确认的摘要。

技术摘要导出只含可核实事实及明确标记的待验证假设，故障发生时和导出时版本分别记录。干净构建可核实Git SHA；未提交本地构建只报告基线与dirty，exactCommit为空，不猜未来提交。软件安装包摘要属于构建证据，与故障数据导出无关。

业务AI审计独立保存，默认无限期。用户主动本地导出可能含业务前后值及操作缘由，不能混入技术故障资料。预览清理时保护所有待撤销审计及undo_of关联连通证据，保留业务记录、号码、幂等回执和正式导出。有后台任务、记录变化、超过10000条或16MiB时停止，未清理或静默截断。实际清理推进数据代际并重置派生增量基准，旧历史快照/任务/游标需重新查询，避免已清理审计从旧镜像再次释放。

## 管理界面与兼容性

敏感权限首次启用由用户一次确认风险；确认本身不授予权限。详情默认折叠。最近调用只表示主程序已收到且核实凭证归属的调用，与已授权、在线及当前会话自动接入分别核验。操作/后台完成、失败、取消在应用内合并轻提示，不使用系统通知或夺取焦点。

`get_capabilities`返回主程序及sidecar实际构建身份、工具集合/数据库schema兼容事实。软件及sidecar须整体升级；配置或隔离stdio验证通过不等于Codex当前会话已自动导入/重载。该严格接入门禁仍关闭，待P8实机验收。

自动检查与浏览器合成UI使用隔离数据。安装/升级、生产授权、当前会话重载和原生字体观感仍需用户在P8统一验收。
