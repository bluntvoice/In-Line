# P5 后台任务与增量同步（v0.5.0开发，待P8统一验收）

## 增量同步

`query_changes` 首次不传cursor，返回授权范围内当前事项的一致分页。按原mode、filters、projection、limit、since及返回cursor继续，直至`fullSyncComplete=true`；之后同一接口读取增量。每页最多100；`hasMore=false`表示本轮追赶完成，仍保留`nextCursor`供下次轮询。不会实时推送。

- `mode=events`返回各条可用变更元数据和页面水位时的当前事项；`mode=current`按本次扫描窗口合并每个事项的最新状态。当前正文不是历史正文，跨页可能再次出现同一事项。
- 可选`since`为RFC3339事件起点；先完成当前状态同步，再从可用历史起点扫描并过滤时间。不能重建早于索引建立时的缺失事件；`historyFloor`和`knownGaps`如实披露。
- GUI及MCP新增、修改、队列、办理、状态、归档、软删除、恢复、永久删除和业务合并在原事务内维护序号与索引。非事项设置变更造成序号间隔是合法情况；事件总数旁证用于识别索引丢失。
- 客户端只会收到此前同步过的对象的裸ID移除标记；从未授权的对象不返回ID、正文、部门或存在性。
- 游标绑定客户端、权限版本、筛选/投影、数据UUID/代际和索引代际。授权改变、恢复数据、损坏索引、过期或全量同步时主程序重启均要求重新开始；完整同步快照10分钟，增量元数据24小时。完整同步完成后的元数据可以跨主程序重启使用。
- 同一游标链保留当前及前一步用于重试，消费下一步后释放更旧祖先；不要并发分叉反复持有旧游标。每客户端最多32个游标记录，全局256个，磁盘16MiB；元数据不含事项正文及凭证。

## 后台任务

`manage_jobs`按action分组，不新增调度器：

| action | 用途 |
|---|---|
| start | 指定kind及arguments启动，立即返回job与独立waiterId |
| list / get | 仅查看当前客户端任务摘要、状态、进度及执行轮次 |
| result | 完整成功后分页领取临时结果，offset/limit每页1–100；重新鉴权和检查范围/代际 |
| cancelWaiter | 指定jobId与waiterId，只取消该等待关系 |
| cancelJob | explicitUserRequest=true，明确取消整个任务，检查点释放资源 |

允许kind：query_tasks、query_task_history、query_work_calendar、get_report_summary及export。前四种复用P2的筛选、字段和统计定义；arguments不得带旧cursor/snapshot。后台内部页固定100，结果领取另选每页数量。export使用P4明确指令、reason、原幂等键及受限CSV/JSON规则，必须有有效写权限；不支持后台备份、恢复、事项修改或批次写入。

同客户端、同参数、同有效授权和数据基准才复用在途任务或10分钟内仍有效的完成结果。`explicitRequery=true`始终创建独立任务，受配额限制。跨客户端不共享。普通客户端断开不终止任务；撤销、授权改变或全局暂停到检查点会终止，部分结果不作为最终成功释放。

主程序最多2个活动任务、每客户端1个；单任务临时结果最多100k行/16MiB，SQLite快照沿用32MiB上限，持久任务目录64MiB/256条。快照、普通查询和临时结果都有独立有界额度；计算阶段不持有设置或取消锁，页间主动让出执行时间。超限明确失败，不把截断称为完整结果。

## 中断、取消和保留

- 限流只暂停后续读取，原子写入继续安全提交或回滚。首次暂停时间固定，最长30分钟，不因重复请求续期；有效新进度后解除暂停。
- 原安全检查点最多24小时恢复，重启不刷新起点；恢复需相同可验证数据基准和现有授权。已校验的前缀只用于核验，不重复追加，也不续期；新进度才能更新检查点。
- 原请求明确`allowLatestAfterInvalidation=true`时，只读任务最多完整重查一次：旧轮结果作废、新轮独立留痕，最终只返回完整有效轮。第二次失效停止。导出不自动换基准。
- 发布文件前保存原键及发布状态；发布中断后只查询原P4回执，缺失回执不会预留或生成新文件。业务写入绝不恢复重放；已提交文件不因取消删除。
- 已完成/失败摘要30天，参数和临时正文结果7天；启动后访问任务及本地管理时实施到期清理，也可在设置手动清理。活动检查点不清理，正式导出独立持续保留，凭证和业务审计不受影响。派生文件仅使用Windows当前用户ACL，无额外缓存加密选项。

## 本地管理与验证边界

设置的“后台查询与导出”集中显示进度/轮次、审阅后取消整个任务及安全清理。AI无法查看或取消其他客户端任务。

接口、SQLite、持久检查点和合成浏览器测试属于开发验证；真实安装升级、原生操作和当前Codex接入仍待P8。P1自动导入/重载尚未实测成功，入口保持关闭。
