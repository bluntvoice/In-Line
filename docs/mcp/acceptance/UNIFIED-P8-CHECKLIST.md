# P8 统一实机验收清单

状态：**待用户验收**。仅P0已验收；P1–P8开发验证不等于实机通过。开发安装包仅本地保存，不进入正式更新通道，P8原报告见[PHASE-08](PHASE-08.md)，2026-10-16最新接入修复包与日志见[首次授权及连接刷新报告](P8-FIRST-AUTHORIZATION.md)。本清单不构成生产安装/数据恢复/Release授权。

## 1. 安装、升级和回退（未执行）

先在测试机或明确授权的本机窗口进行。记录安装前程序版本、数据schema、事项数量、业务/备份摘要以及独立授权状态；保留受保护的可回退副本。升级本次包后核对主程序/sidecar为同一套0.5.0、schema14，旧库自动迁移备份、正常打开、完整性/FK及事项/号码/历史保留。原机授权不能被业务备份覆盖，跨机凭证应拒绝。安装失败不得覆盖原库。

回退旧二进制和恢复业务数据分开判断；旧程序不能直接打开新schema。不要直接还原早期checkpoint，避免丢失之后真实工作。NSIS静默指定其他目录仍可能改注册表/快捷方式，不视为无影响隔离。

## 2. 旧界面与编号（待实机观感）

- 更纱黑体UI SC，100%/150%及实际常用屏幕：待办/暂缓/归档数字胶囊和逾期图标垂直居中，子任务数字与文字同一基线；无字号跳动或裁切。
- 事项详情加入日期通过编辑修改；红色删除为外框+图标+文字，与同排按钮对齐。
- 统计中心选月/自定义范围→打开事项→返回，保留原范围及日期。
- 右键设置单事项编号色，重开仍保留；未来/加急显示自选色，逾期或最高优先级变红，警示解除恢复自选色。
- 创建未来子任务：显示“自动预占 · 已开启”，不显示不可点击关闭开关；今天保留入队开关，父子日期创建后独立，号码不重复/回收。

## 3. 授权和严格客户端接入（阻断项）

常规读取默认开、完整读取/写入默认关。敏感权限首次风险提示取消不授予，确认只记录提示；按选择独立授权，部门AND类型限域。暂停、撤销、轮换立即生效，旧客户端无读写，不能自动复活。最近调用事实与“已授权/在线/当前会话验证”不混淆。

**首次授权及安全导入门禁已修复，当前桌面会话仍待验证**。用户已批准绑定所选客户端的sidecar安全刷新已授权凭证，替代原生重载；同一stdio连接的隔离回归通过。安装新程序后，最终接入出口必须实际“选择客户端和权限→授权并复制提示词给当前Codex→自动导入、原连接刷新、直接get_capabilities及授权读取成功”，核对客户端ID、有效权限和范围；用户不需手动填Token、环境变量、重启或重连Codex，全过程不暴露长期凭证。当前旧程序尚未替换，原挂载会话未通过认证；导入器的配置验证子进程、预备刷新报告均不算此项通过。可先验收软件内已完成部分，此项保留未通过，整体P8不标完成、不进入P9。

## 4. 读、写、回执和撤销

在隔离客户端/合成事项验证常规投影不泄露详情/联系人/办理自由文本；完整权限才读取；旧两个报告工具强制认证/每页100，跨页同快照，不串客户端。普通统计/日历与相同条件UI一致。

明确要求创建/局部编辑/状态/加急/真实办理；与GUI同规则、准确ID、疑似重复不自动合并。相同幂等键重试只一次，异参数拒绝；字段冲突不覆盖。AI仅提交撤销申请，在软件内审阅前后变化后批准或拒绝；授权/当前状态变动应拒绝不安全撤销。结果未知先用原键核验，禁止新键重做。

## 5. 复杂动作和批次

队列/未来改期/两级子任务/软删除恢复按现有业务规则；不开放永久删除/覆盖数据库/附件操作。dryRun不占号码、不留业务记录；20事项混合批次任一失败全回滚，歧义不猜。多事项改期在软件内一次审阅整批，取消零写，批准前现状改变整批拒绝。备份/导出须明确要求、限字段/范围，AI不读取整个备份或指定任意路径。

## 6. 后台任务、增量和缓存

任务进度/轮次正确；取消等待不取消共享任务，软件内取消需明确确认。断开、暂停/撤销、限流和重启按原30分钟/24小时期限，不续期；只读基准失效最多一次完整重查，写入不重放。增量游标失效明确要求全量重同步。

统计溯源绑定原快照/权限；缓存只在相同基准复用，写入或权限变更后失效。安全清缓存不删事项、审计、回执、检查点、正式导出；有活动任务时审计清理拒绝。

## 7. 故障和维护

仅基础状态筛选；同类重复计证据不新增轮次，实际恢复后复发才新轮，30天3轮提升关注。标待验证不算恢复；两次相关真实成功且首末≥30秒才恢复。P0/P1不可静音；普通7天到期恢复，未解决不按年龄删，已恢复30天。损坏诊断文件应显示存储不可用且保留原字节，不测试性破坏生产文件。

CSV/JSON先脱敏预览，取消或保存选择取消零文件；确认后保存内容与预览一致，只创建新文件。无原始完整日志、Token、路径、其他客户端业务，无故障哈希清单；提示词由用户手动转交，不自动上传/调用AI。审计无限期默认保留，手动清理保护待撤销关联证据及所有幂等回执，清理确认期间变化应拒绝。合并提醒不抢焦点、不弹Windows通知。
