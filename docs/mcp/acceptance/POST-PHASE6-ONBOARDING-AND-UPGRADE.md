## 3. 代码修改

### 接入弹窗

- 首屏统一“AI 接入（MCP / CLI）”与“连接 AI”；必要选项在同一原生 modal dialog 内，支持 Escape、焦点限制及返回入口焦点。
- 默认常规读取，完整读取及写入默认关闭。部门/类型范围为可选项。
- 如请求权限被全局关闭，弹窗要求明确勾选，同时说明其他已有相应授权也会恢复；解除全部暂停亦须单独勾选。敏感权限仍需首次说明确认。不默认解除暂停或扩大全局权限。
- 签发成功即保留短期回执；复制失败只重试复制，关闭重开也保留提示词，过期不能复制。明确发起新的接入后才重新授权。
- 管理、轮换和撤销保留于折叠区。配置验证、CLI 验证及当前 MCP 会话验证保持分开。

### 授权存储保护

- MCP / CLI 签发和轮换必须绑定同一安全存储路径。
- 授权变更前比对磁盘完整记录，拒绝用过期 GUI 快照覆盖磁盘；保存后独立完整回读才更新内存、返回回执。失败清理本次未成功签发的包。
- GUI 读取授权状态时检查磁盘与内存，不再显示仅内存存在的授权为有效；返回明确的 `authorization_storage_mismatch`，不混用业务写入结果不确定的提示。
- 导入包对应 Codex 授权缺失时返回 `import_authorization_missing`，不消费包、不改配置、不自动恢复或补造权限。撤销/暂停/轮换保护保留。
- 上述为防止错误成功及安全拒绝的修复；新安装版实际签发、落盘与当前会话认证仍须实测。

### 字体、字号和安装器

- 字体读取及真实 FontFace 加载临时失败时，最多追加 150 / 500 / 1500 ms 三次重试；窗口重新获得焦点时再读。保留已加载字体，旧异步响应不得覆盖新选择。
- 字号读取同样重试，保留已加载数值；每个 WebView 单独恢复缩放。全局应用状态在全部窗口成功后提交，失败允许再次尝试；仍只接受既有六档。
- 没有修改用户数据库默认值、迁移 schema 或字体缓存位置。升级迁移回归增加推荐字体和 130% 字号跨迁移及重开保留断言。
- NSIS 使用 Microsoft YaHei UI 9pt，只将维护页原 8u 单选项改为 14u，保留原位置、样式及安装逻辑。完整原生 DPI 显示和安装升级仍待实机。

## 4. 实际自动备份规则（本次不改变）

代码依据：`database.rs` 的 `open_root`、`backup_connection`、`prune_backups`、`restore_backup`。

| 项目 | 当前规则 |
| --- | --- |
| 位置 | `%APPDATA%\in-line\backups`，与业务库 `%APPDATA%\in-line\inline.db` 同一数据根目录 |
| 自动触发 | 启动打开数据库时，按本机当天日期检查，若没有当天 `-auto.db` 文件则生成一份；不是定时器、不是每次修改或退出时备份 |
| 跨日常开 | 持续运行跨过午夜不会因此自动新增，下一次启动才检查当天备份 |
| 自动保留 | 启动时只对 `-auto.db` 按修改时间保留最近 30 个文件；不是保证连续 30 天 |
| 内容 | SQLite `VACUUM INTO` 一致性完整快照，包含事项、记录及软件设置（包括字体选择和字号） |
| 不包含 | 下载字体缓存、独立 MCP/CLI 安全存储和外部客户端配置/凭证 |
| 迁移保护 | 旧 schema 打开前校验并创建 `before-migration` 快照，再迁移；不会因同日已有自动备份而跳过该保护 |
| 恢复保护 | 有效备份合并前创建 `before-restore`；外部导入保留为 `import`，手动备份为 `manual` |
| 非自动文件 | manual / import / before-restore / before-migration 不受“30 个自动备份”规则清理 |
| 主动清理 | 软件内“仅保留最近 5 个”是另一项需用户确认的操作，会对备份目录直接 `.db` 文件统一按时间保留 5 个，不仅自动备份 |
