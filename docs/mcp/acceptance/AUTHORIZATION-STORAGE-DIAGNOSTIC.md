## 实现

- GUI 高级管理提供“检查授权存储”；每个客户端提供“接入诊断”，包括已撤销记录。即使授权列表读取失败，通用诊断入口仍保留。
- GUI 在当前宿主内读取摘要，并启动同目录 sidecar 的专用只读诊断模式。该模式在构造运行时凭证提供器之前分流；不调用导入器、不访问接入包、Codex 配置、备份、业务数据库或 MCP 管道。
- 不用 `Security::open`，只用既有 `Security::read_at`，因此缺失文件/目录不创建，损坏文件不修复。没有授权、轮换、撤销、配置更新和业务写入。
- 报告包括进程/构建、原始与解析后的安全根目录、卷/文件标识、大小、修改时间、授权 revision/记录数、所选客户端 SHA-256 指纹及是否存在/类型/撤销摘要。类型只输出白名单值。Token、Token hash、管道秘密、原始客户端 ID、名称和权限范围不进入 DTO。
- GUI 内存与磁盘完整一致性在内部比较；两端通过文件标识及 revision 比较。读取前后元数据变化时，将一致性结果设为未知，避免把并发写入误判为稳定状态。
- 独立诊断有 5 秒超时、隐藏窗口、关闭 stderr、输出结构/大小检查；不回显任意子进程错误或原始输出。子进程不继承 MCP 凭证变量，不修改系统环境变量。旧 sidecar 不支持模式时报告 `incompatible`，保留 GUI 摘要。
- 本机路径在界面明确提示，只有用户点击时复制；不自动上传或持久化诊断。`configurationVerified` 和 `currentSessionVerified` 恒为 false。独立诊断进程不用于冒充当前会话认证。
