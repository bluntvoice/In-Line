# P8 集成、契约与缺陷回归规程

2026-10-12。按用户最新授权，各阶段开发完成后独立提交推送，P8统一验收。开发提交不代表用户验收，不创建accepted Tag；P8未通过不进入P9。三份原输入与144项产品决定保持不变。

## 契约与迁移

当前API v1、schema14、16工具。`contracts/tools-v1.json`从P7实际sidecar的tools/list读取，经审阅固化完整输入schema及协议注解。`scripts/verify-mcp-contract.mjs`无凭证运行实际sidecar，只初始化和读工具表；工具移除、参数或注解变化直接失败，不自动再生成基线。CI执行debug产物门禁，开发/正式包流程执行两个实际sidecar输入门禁，在上传或发布之前失败。PowerShell每条原生命令独立检查退出码，防止前一步失败被最后一个成功命令掩盖；开发/Release已有复合测试步骤同样补强，不改变测试断言。

两个已发布工具`get_report_summary`、`list_report_items`名称及日期调用仍保留，旧日期参数真实调用和业务口径断言见`src-tauri/tests/mcp_stdio.rs`。新增认证、常规投影隐藏自由文本、单页最多100条属于已确认的安全变化。旧匿名连接会被拒绝；后续分页须绑定同条件快照/cursor。迁移使用独立客户端授权，不把长期Token放进启动参数、聊天或故障导出。

MCP-099是允许下次正式版直接移除旧接口，实施仍需事先确认。本阶段没有移除旧两工具，也没有开始90天倒计时。将来批准移除时，逐项列出旧调用、新查询/报表等价调用、参数和结果差异，再更新契约基线及长期测试，不能靠重新生成JSON绕过门禁。严格“选择客户端/权限→复制提示词→自动导入并当前会话验证”的Codex流程尚未成功，入口关闭；隔离导入器通过不能代替本会话证明。

## 多层证据与回归

1. 全量前端及Rust涵盖旧事项、未来编号、子任务、统计、备份和MCP领域/SQLite/IPC/stdio、两个以上独立授权客户端、字段冲突、原子回滚、旧快照、撤销/暂停/轮换、回执与后台期限。实际命令/数量见[PHASE-08](acceptance/PHASE-08.md)，使用合成临时数据库。
2. 浏览器组件回归涵盖撤销、批次审批、任务取消、缓存清理、权限和故障导出；真实更纱WOFF2验证胶囊。API夹具验证交互，不当作原生安装或生产客户端通过。
3. 当前会话只调用已挂载的get_capabilities；不另起业务服务、不自动修改Codex配置、不从环境/文件读取Token。结果记录`P8-current-session.json`。
4. NSIS只构建与回读输入，不安装生产程序。升级保留、原生多屏字体、生产授权/暂停/轮换以及当前会话自动重载需按[统一验收清单](acceptance/UNIFIED-P8-CHECKLIST.md)实机验证。
5. 大规模1千/1万/10万数据的内存峰值和GUI输入延迟预算没有完整测量，不声称性能已达标；限额/取消/跨客户端/缓存配额已有合成断言。如实机明显卡顿，保留构建、规模、时间与可复现步骤后定向补测。

## 本次已证实缺陷

诊断私有JSON为合法类型但含i64/u32/u64极值时，P7未拒绝，时间差/计数可能溢出。用户2026-10-12选A批准按现架构修复。首次失败`P8-numeric-first.txt`明确accepted corrupt started；永久测试`typed_numeric_corruption_is_rejected_without_overwriting_evidence`和`extreme_live_values_cannot_panic_or_replace_the_last_valid_snapshot`留在Rust全量CI。

修复：Unix时间只接受1970至9999年范围；轮次/证据/验证计数与状态校验；容量复验；计数checked_add；clone状态在持久化前校验。损坏文件保留原字节，服务拒绝操作，不写空文件覆盖；不改业务记录、权限或手动恢复。受影响MCP-050/088/120–138、051/091/141–143重测。P7保留包是修复前历史产物，不可拿来验收此修复。

## 首次失败、重跑和隔离

保存首次日志、精确Commit、命令/退出码/测试名；区分夹具、资源、网络与产品。关键安全/事务/数据失败必须找因、修复、定向及全量回归；仅重跑变绿不能放行。失败后停在P8，不推断验收或发布。

正常重构允许等价替代测试；删除/削弱关键断言须先问用户。非关键不稳定测试只有用户明确批准、记录替代验证、责任/恢复条件及截止才可临时隔离；关键测试不隔离。本次没有ignore/skip、删测试、弱化断言或隔离。GitHub首次CI链接和精确SHA保留；本地首次数值失败保留。远端REST第一次EOF属于传输读取失败，重试成功不代替任何产品测试。
