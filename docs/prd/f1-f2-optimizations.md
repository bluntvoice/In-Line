# 统计中心时间范围与事项时间线优化

## 背景与基线

本工作基于 v0.4.0 的 `main`（`1baac96252af2665274f2a955b3adacfa80519fd`）。统计中心当前有五个预设，切换页面会重新挂载面板并重置日期。事项时间线逐条呈现 `task_logs`，一次业务操作可能同时产生状态、出入队、加急和结果日志。

## F1 统计中心

| 选项 | 查询日期（首尾含当日） | 对比 |
| --- | --- | --- |
| 本周 | 设置的周起始日至今天 | 上周同期 |
| 上周 | 上一个完整自然周 | 上上周 |
| 本月 | 本月首日至今天 | 上月同期 |
| 上月 | 上一个完整自然月 | 再上一个完整自然月 |
| 本季度 | 本季度首日至今天 | 上季度同期 |
| 上季度 | 上一个完整自然季度 | 再上一个完整自然季度 |
| 自定义 | 用户输入的开始日和结束日，允许跨月、季度和年 | 紧邻之前的等长日期范围 |

月、季度的同期从前一周期首日起算，取相同的已过自然日数，最多取完前一周期。选择本周和上周时遵循周一起算或周日起算设置。所有日期以本机本地日历为准，传给查询接口时仍用首日零时至末日次日零时的半开边界。空白或逆序的自定义日期展示校验信息。

七个选项按表中顺序显示，空间不足时换行。预设和自定义日期保存在主窗口的应用状态中，保留至窗口关闭，覆盖进入详情、关闭详情、切页及返回。统计汇总、周期对比、趋势桶钻取、事项明细、图表导出及报告生成继续使用同一当前区间。现有办理事件、按事项去重和趋势聚合规则继续沿用。

主要路径为 `src/App.tsx`、`src/components/StatisticsPanel.tsx`、`src/lib/statistics-range.ts` 与 `src/styles.css`。

## F2 事项时间线

| 事件来源 | 原始记录与展示 |
| --- | --- |
| 主入口创建与子任务创建 | 创建和取号日志、子任务所属关系，加急资料可能另记。组内保留创建结果和所属关系。 |
| 修改事项或状态 | `task_logs` 记录编辑、状态及出入队，`status_history` 保留结构化状态变更。组内突出状态或队列结果，原条目可展开查看。 |
| 本轮已处理、已完成、补录办理 | 状态历史、`task_queue_entries` 和 `task_work_events` 分别保留业务事实。时间线突出本轮或补录结果。待材料等状态按实际结果表达。 |
| 暂缓、重新入队、重新开启 | 入队显示取得的队列编号，具体入队日期和原备注仍可查看。退出队列的原日期、序号和原因仍可查看。 |
| 归档、删除、移入和移出回收站、事项合并 | 在各事项自己的时间线突出主要结果。既有被合并记录及父子关系按当前域规则归属。 |
| 人工备注与作废办理 | 普通备注独立呈现并保留现有编辑、删除动作。办理项及作废审计记录继续独立呈现。 |
| 旧数据库及备份 | 无可靠操作标识的历史逐条显示。导入、合并和升级沿用基线行为。 |

新操作在已知的业务写入事务中、按事项标记同一操作的自动日志。时间线仅按显式操作标识折叠，连续重复操作、相同时间戳及交错备注始终独立。组合行提供原始细节。操作标识随自动日志类型保存，旧界面仍可读取原文，备份复制既有字段即可保留关联。写入事务为新插入的自动日志记录操作标识和原归属事项；读取时还原日志类型并按标识分组。合并事项移转既有记录时保留其原操作标识。相同时间戳按记录 ID 定序。现有 schema v8、原始历史、办理统计、状态历史、队列记录、独立审计、MCP 授权与安装器均沿用当前机制。

主要路径为 `src-tauri/src/database.rs`、`src-tauri/src/models.rs`、`src/types.ts` 及 `src/components/TaskDetail.tsx`。F2 不要求数据库迁移。
