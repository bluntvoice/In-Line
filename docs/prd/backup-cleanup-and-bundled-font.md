# v0.5.0 备份清理与内置字体

> 用户于 2026-10-03 授权；本节补充既有备份及字体 PRD，不改变历史发布记录。

- 可恢复备份工具栏增加“仅保留最近 5 个”。手动触发，显示清理数量并一次确认；不增加后台自动清理。
- 按文件修改时间从新到旧保留 5 个，不足 5 个不删除，同一时刻按文件名稳定排序。导入置顶仅影响展示，不影响保留判定。
- 覆盖备份目录中的手动、自动、导入及恢复前数据库备份；只处理目录第一层普通 `.db` 文件，不递归、不跟随符号链接或 Windows 重解析点，不触碰当前数据库、外部原文件及非数据库文件。
- 清理结果显示实际成功与失败数量，失败文件保留并显示原因，刷新列表后可以重试。清理不新建备份、不合并或更改事项及设置。
- 默认字体内置更纱黑体 UI SC（Sarasa UI SC），从官方 GitHub v1.0.42 获取并核对发布包 SHA-256；包含 Regular / SemiBold / Bold 全字形 WOFF2 及原 OFL 许可证和来源记录。
- 本地字体资产随应用打包，不联网加载、不安装到 Windows。使用独立 CSS family，避免同名字体版本冲突。已有自定义字体选择保留；原选择为更纱 UI SC 时也可离线使用内置字体。
- 字体选择器标识“更纱黑体 UI SC · 内置默认”；恢复默认及缺失字体回退均使用内置字体，覆盖主界面、悬浮窗、快捷新增和更新进度；字体搜索及其他系统字体仍可用。
- 验证：隔离文件夹 0—5 / 多备份 / 相同时间 / 类型混合 / 子目录和链接 / 占用失败及重试；真实 SQLite 事项和设置保留；隔离浏览器确认加载打包字体而非系统同名字体，验证、字重、默认恢复、缺失回退和窗口布局。开发安装包仍通过 Actions Artifact 分发。

## 本地验收记录

- 102 项前端测试、TypeScript / Vite 构建、Rust 格式检查、57 项 Rust 库测试及 3 项 MCP 测试通过。
- 隔离 SQLite 和目录验证 0—5 个备份不删除、混合类型按真实时间保留最近 5 个、相同时间稳定排序、外部原文件／子目录／非数据库文件保留，真实 Windows 文件占用时部分成功并可重试；事项和其他设置保持。符号链接夹具仅在系统允许创建时运行。
- 隔离浏览器通过 CDP 确认实际使用打包的 custom font，加载 400 / 600 / 700 字重，无字体请求失败；默认／缺失回退、既有 Sarasa 选择、其他系统字体、重载和辅助窗口同步通过。浏览器 API 和跨窗口广播使用隔离模拟，不代替原生安装实测。
- 备份按钮确认取消不写入，成功清理、部分失败、错误提示、重试、不足 5 个禁用及进行中禁用通过。1280 / 980 设置布局及 125%—200% DPI 列表布局通过；当前系统真实枚举 342 个字体系列，四种字体的列表、详情、统计及重开回归通过。
- 未操作用户实际备份或数据库。新 Actions 安装包仍需 Windows 安装环境最终验收。
