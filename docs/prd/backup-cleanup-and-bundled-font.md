# v0.5.0 备份清理与推荐字体

## 2026-10-10 字体切换后的数字胶囊对齐

用户反馈更纱黑体UI SC下侧栏数字胶囊观感偏移。普通数字及逾期图标胶囊统一22px高度、12px字号/单行行高、flex双向居中及等宽数字；不为特定字体设置固定偏移。推荐WOFF2摘要及实际custom font确认后，四种字体、100%/150%布局测量与合成截图验证见MCP P2验收报告，真实WebView/DPI观感仍需用户验收。

> 用户于 2026-10-03 授权；本节补充既有备份及字体 PRD，不改变历史发布记录。

- 可恢复备份工具栏增加“仅保留最近 5 个”。手动触发，显示清理数量并一次确认；不增加后台自动清理。
- 按文件修改时间从新到旧保留 5 个，不足 5 个不删除，同一时刻按文件名稳定排序。导入置顶仅影响展示，不影响保留判定。
- 覆盖备份目录中的手动、自动、导入及恢复前数据库备份；只处理目录第一层普通 `.db` 文件，不递归、不跟随符号链接或 Windows 重解析点，不触碰当前数据库、外部原文件及非数据库文件。
- 清理结果显示实际成功与失败数量，失败文件保留并显示原因，刷新列表后可以重试。清理不新建备份、不合并或更改事项及设置。
- 2026-10-03 用户改为应用专用推荐字体，取消随安装包内置。默认及缺失回退使用 Windows 字体栈；已有自定义系统字体选择保留。
- 设置中提供“推荐字体 · 更纱黑体 UI SC”，用户主动点击“下载并启用”后后台下载；启动和日常使用不联网。独立于检查软件更新，不使用 Release 安装包通道。
- 下载固定 GitHub commit 中的官方 v1.0.42 全字形 WOFF2：Regular 8.34 MB、SemiBold 8.48 MB、Bold 8.62 MB，共 25.44 MB；固定文件名、大小、SHA-256 校验，不跟随重定向，不接受自定义源。保留原 OFL 许可证和来源记录。
- 缓存位于应用本地数据目录的 recommended-fonts/sarasa-ui-sc-1.0.42；逐文件下载到临时文件，校验后提交，仅完整的三个字重可启用。失败不修改字体设置，显示原因并允许重试，已校验字重复用；软件退出后未完成文件下次主动下载时重试。
- 下载关闭设置后仍继续；完成后自动保存推荐字体选择并广播所有窗口。如果用户下载过程中主动选择其他字体，保留用户的新选择。
- 不安装到 Windows、不修改系统字体配置；使用私有 CSS family 和仅暴露三份已校验 WOFF2 的本地协议，已下载后离线使用且软件更新无需重新下载。字体缓存不随事项数据库备份迁移；新电脑恢复设置后回退默认，用户主动重新下载。
- 新增“界面大小”：100%、110%、120%、130%、140%、150%，恢复默认为 100%。使用 WebView 缩放同步调整文字、控件、间距，主界面、悬浮窗、快捷新增、更新进度均生效；悬浮窗及更新进度窗按比例调整外框以容纳固定控件，主界面与快捷新增保留当前窗口大小及滚动。不改变取号图片导出或图表导出尺寸。设置保存并随备份恢复，未增加数据库 schema。
- 验证：隔离文件夹 0—5 / 多备份 / 相同时间 / 类型混合 / 子目录和链接 / 占用失败及重试；真实 SQLite 事项和设置保留；隔离浏览器确认加载打包字体而非系统同名字体，验证、字重、默认恢复、缺失回退和窗口布局。开发安装包仍通过 Actions Artifact 分发。
