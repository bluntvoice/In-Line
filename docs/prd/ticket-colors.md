# 编号配色设置

> v0.5.0 开发补充；用户于 2026-10-03 确认 16 个官方候选色。

## 行为

- 软件设置新增编号配色，普通、未来、加急三类分别选择官方色或输入 HEX 编码。
- 普通默认 `#0B3A82`，未来默认 `#3F766E`，加急默认 `#C43D4B`。未来事项兼有加急属性时沿用既有规则，编号优先显示未来色，加急标签保持原样；实际入队后使用普通／加急色。
- 输入支持带或不带 `#` 的 3／6 位十六进制色，保存时展开为大写 `#RRGGBB`；输入非法值时给出具体提示，不写入设置、不改变当前颜色。
- 候选色点击后保存；编码输入通过应用按钮或 Enter 保存。保存成功后所有使用编号组件的窗口即时生效，关闭重开后保留。
- 编号文字根据底色自动选择黑／白，以较高对比度方案显示，浅色可读。其他状态标签、加急标签、逾期提示及取号卡片的配色不属于此次设置范围。
- 恢复默认一次性恢复三类底色，并清除尚未应用的编码输入。
- 使用现有 SQLite settings，单个 `ticket_colors` JSON 设置记录完整三类颜色；无 schema 迁移。沿用现有备份导入校验及数据变更广播；缺失或损坏的配置安全回退默认值，保存失败保留原配置。

## 验收

检查 16 色完整性、三个独立设置、HEX 规范化及拒绝非法输入、浅色文字对比度、候选色保存、跨窗口同步、重开持久化、原设置不受影响、恢复默认清除输入，以及保存失败不改变已有颜色。SQLite 使用隔离数据库验证读写、重新打开及备份恢复；最终测试包由 Actions 开发工作流生成，不创建 Tag 或 Release。
