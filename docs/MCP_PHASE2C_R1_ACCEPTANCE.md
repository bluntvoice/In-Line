## 根因与修复范围

旧模板先删除快捷方式，再删除 ARP 卸载注册项；后一步拒绝访问时，`InLineOnAbort` 只恢复五文件组。创建/更新快捷方式的 NSIS/COM 插件调用没有实际结果核验，删除也没有存在性回读，导致必要操作失败仍返回成功。目录记忆默认值写在注册阶段前半段，没有随失败恢复。

R1 沿用 NSIS → 有限 PowerShell → C# 保护程序，把固定的本产品元数据并入现有 journal 与恢复路径：

- 文件组仍须全体独占、验证路径/文件身份、备份/校验后才修改。无任何按名称终止、常驻进程或连接恢复机制。
- 在修改前保存本产品快捷方式原字节、摘要、ACL、时间。创建前回读目标，必要路径被外部快捷方式占用则明确失败；卸载跳过非本产品目标。
- 对目标快捷方式取得独占读/写/删除句柄，已确认归属后再次核对原字节；新建链接先在私有临时路径准备并确认目标，包含 AppUserModelID。写入 flush 后比对摘要，删除在 finalize 回读存在性。
- 安装应用本产品 ARP 注册字段和目录记忆值时核对 before/planned-after，逐项回读结果。失败恢复只限本产品两个固定键的已捕获状态，不实施通用注册表事务或递归删除注册树。
- 卸载注册处理失败时，保留句柄撤销快捷方式删除并恢复字节，同时恢复程序组；失败不能作为成功卸载返回。
- 显式恢复拒绝覆盖并发替换的快捷方式；注册值与已捕获/计划值不一致也拒绝覆盖。恢复无法确认时保留 journal/备份和业务启动屏障，不宣称完整回滚。
- 保持原有 ARP `EstimatedSize` 口径：Tauri 渲染清单的源文件估算值加上实际生成的卸载器 KiB。独立清单摘要与候选 SHA/包来源绑定，安装后按实际卸载器长度精确回读；不顺带重做上游重复目标源条目的体积统计。
- 目录策略：安装/升级成功更新默认值，失败恢复原值或原本不存在状态；正常卸载保留最后目录；卸载失败保持原值。
- 完成页的额外桌面快捷方式选择单独验证，失败给出可选动作警告，不将主体安装成功当作该链接创建成功。没有自动退出/终止占用程序。

NSIS 官方虽说明 `CreateShortCut` 设置错误标志，但本次不以这一标志代替真实结果检查。[NSIS 命令说明](https://nsis.sourceforge.io/Reference/CreateShortCut)。注册键删除的 Windows API 具有自身权限、视图和句柄语义，故对返回结果及磁盘/注册状态分别核对。[RegDeleteKeyExW](https://learn.microsoft.com/en-us/windows/win32/api/winreg/nf-winreg-regdeletekeyexw)。

关键代码定位：`InstallMetadata.cs:138` 准备快照及句柄、`:188` 应用与回读、`:208` 安全恢复、`:234` 完成核验、`:239` 失败预检占位清理；`InstallGuard.cs:220` 显式恢复、`:252` 元数据应用、`:268` 错误恢复、`:161` 可选桌面动作。

源码层面的撤回仅在后续用户批准提交后通过独立 revert 处理；当前正式开发分支只有已接受的测试资产提交。临时候选分支及历史失败记录保留。

补充实际退出码边界：NSIS 原卸载启动桩在部分失败场景仍可退出 0，而其真正执行的 `~nsu*.tmp/Un.exe` 退出 1；本轮持有该进程句柄读取实际退出码，并核对结果状态，没有用启动桩的 0 判定通过。这个上游启动桩语义没有在 R1 擅自修改，外部自动化不可仅信任最外层退出码。

已有 ARP 注册若指向其他目录，元数据层会停止，不擅自接管另一目录的安装。自动目录迁移和 Shell 固定/最近项目清理不属于本轮通过项。实际完成页的可选动作提示仅完成实现及组件负向验证，仍须人工向导验收。

未来正式提交的 Git SHA 会不同于本次候选，发布前须从最终源码重新构建/核对身份并完成最终回归，不能将本次候选包冒充后续正式提交的二进制。

这不是文件与注册表之间的 Windows 跨资源原子事务。物理断电、磁盘设备失败、注册值极短窗口的外部并发写入、恢复自身再失败，以及企业策略真实限制，仍不能承诺无条件自动修复。窗口/托盘交互、真实偏好开关语义、第二用户会话、重定向/OneDrive 桌面及极长参数路径、真实旧业务数据库迁移、完整业务授权矩阵及当前正式 Codex 会话不因本轮通过而自动验收。
