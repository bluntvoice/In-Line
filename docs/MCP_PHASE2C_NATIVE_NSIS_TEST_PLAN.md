## 1. 环境与隔离边界

首选可恢复快照的独立 Windows 11 x64 VM，使用专用测试账户及独立虚拟磁盘。记录 OS build、账户 SID、权限、NTFS 卷、系统 .NET/Windows PowerShell x86/x64、WebView2、企业策略和杀软版本。后续需要 Windows 10 或第二用户时单独建测试分支快照。

禁止挂载宿主正式安装目录、AppData、Codex 配置或真实授权文件；禁止宿主文件夹写穿透，不在 VM 安装/登录真实 Codex 会话。文件传入仅限已校验安装包和无业务测试工具。MCP 客户端用 VM 内独立 stdio 测试宿主，凭证仅在 VM 内合成/签发，不导入任何正式凭证，不在命令行或报告输出 Token。

“同一 Windows 用户下只换安装目录”不足以隔离：产品标识对应的 HKCU、用户数据、快捷方式、自启动和可能的 IPC 仍可能共用。只在同机完全隔离目录测试时，必须额外具备独立 Windows 用户及配置/注册表/IPC 隔离证明，并经用户重新认可；默认不采用。

VM 内建议路径为 `C:\P2C-NsisLab\case-<id>\install`、`evidence`、`backup`，开始时保存干净 VM 快照 S0。任何安装、卸载、策略修改、故障注入或测试进程中止只作用于该 VM；宿主当前 Codex/In-Line 及正式目录不在范围内。当前回合不会创建 VM、改策略或启动安装器。

## 3. 基准数据与证据模型

VM 内建立最小合成事项、用户偏好、客户端授权和 MCP 配置，并加入非目标 MCP 项及一个异目录同名 fixture。旧版不具备的授权功能单独在新版基线快照建立，不假设 v0.4.0 支持完整 MCP。客户端凭证保持 VM 本地；只能报告存在性、文件摘要、受限 ACL、客户端标识脱敏值、权限/范围和授权修订对比。

每个用例按 S0 或指定基线快照开始，不叠加失败残留。安装前、退出/失败后、恢复后分别采集：

| 状态组 | 必须回读 |
|---|---|
| F：程序文件 | GUI/MCP/CLI/WebView2Loader.dll/uninstall.exe 的存在性、大小、SHA-256、时间、DACL；事务目录、journal、备份和互斥锁；不盲删标记 |
| M：安装元数据 | 实际 HKCU 注册位置（32/64 位视图）、厂商目录项、ARP DisplayVersion/InstallLocation/MainBinaryName/UninstallString、对应键 ACL；导出只限产品键 |
| L：快捷方式 | 桌面/开始菜单路径、目标、参数、工作目录、AppUserModelID；自启动项及原偏好对比；不枚举或修改其他产品项 |
| D：数据与授权 | 合成 DB 完整性及业务记录/Schema、偏好值、授权权限/范围/修订、MCP 配置其他项的前后差异；DB 如合法迁移则比较逻辑数据，不要求迁移后的字节相同 |
| P：进程 | 被测试安装器/卸载器及其临时副本、GUI、CLI/MCP、同名非目标实例的 PID、创建时间、路径、用户；记录是否正常退出及原因 |

保存 NSIS 详细日志、进程退出码、截图和上述结构化回读；退出码 0 只是证据之一。原生日志及注册备份先保存在 VM 内，脱敏审查后才传出；不上传 Token、真实库或系统-wide 注册表转储。

## 5. 一致性判定与恢复规则

| 结果类别 | 判定与后续 |
|---|---|
| 安装成功 | 五文件完整且与同一候选包匹配；安装/卸载路径、版本与快捷方式均正确；事务完成；数据/授权符合预期 |
| 卸载成功 | 受管程序组移除；产品安装元数据和指向该安装的快捷方式清理正确；保留的用户偏好/数据和未知文件有明确记录；按当前策略保留的自启动偏好/Run 项单列，并验证目标缺失及重装后的影响 |
| 失败且完整回滚 | F/M/L 全部回到用例基线（或已批准的明确状态），D 未损；再次启动、安装/卸载行为可核验。只恢复 F 不满足这一判定 |
| 失败且仅程序恢复 | F 已恢复但 M/L 改变：明确“不一致/未完成恢复”，停止该用例；保留证据，不运行业务，不算通过 |
| 无法验证或恢复失败 | 不重试写入、不清理事务标记；保存 VM 快照及证据，停止并报告。只有用户确认恢复动作后才进入恢复演练 |

恢复演练分两层：

1. 产品现有能力：核对 guard 源码、路径所有权、journal 固定文件名、原备份及当前摘要后，在同 VM 对程序组执行显式回滚；记录是否完成，不宣称它恢复 M/L。
2. 独立实验恢复：优先回到包含 F/M/L/D 的 VM 基线快照。产品注册表/快捷方式的外部备份可用于获准的定点恢复演练，严格限定原用户、原目录及原有键/链接，禁止全局导入或覆盖其他软件。此手段不是产品已经具备的自动回滚。

每次恢复后再次回读 F/M/L/D/P 并验证可重试性。若实际发现程序与元数据不一致且现有 guard 无法完整恢复，应把生命周期验收判失败，另提最小修复方案确认后开发，不能仅因 VM 快照可还原而批准产品升级。
